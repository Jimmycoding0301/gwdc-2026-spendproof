# Hackathon scope disclosure

## English

This repository is the GWDC 2026 Korea submission snapshot assembled on **2026-09-29 KST**. The original local workspace did not contain a usable Git commit history before packaging, so this document does not claim file-by-file provenance from commit timestamps.

### Existing before the official hacking window

- The SpendProof product concept and an early local prototype existed during pre-event preparation on 2026-09-27.
- The prototype already used common open-source building blocks including React, Vite, Express, TypeScript, Vitest, viem and Zod.
- General spending limits, allowlists and payment logs are established industry patterns and are not claimed as original inventions.

### Work completed or verified for the GWDC submission

- The concrete cross-border invoice and fee-overrun incident story was packaged as a repeatable demonstration.
- Qwen3-32B was configured as the event model and a real Kiln tool-calling flow was validated.
- The policy release gate, deterministic boundary generation, read-only receipt and SDK/CI path were integrated into one review flow.
- A zero-value Base Sepolia evidence digest was submitted, independently rechecked and documented.
- Security boundaries, test coverage, submission documentation and a standalone repository package were completed.

# Public evidence

[`base-sepolia-anchor.json`](base-sepolia-anchor.json) is a deliberately reduced public record of the confirmed zero-value SpendProof evidence anchor. It contains public chain fields only and no private key, raw signed transaction, Kiln credential or original business evidence.

Independent explorer: <https://sepolia.basescan.org/tx/0x10f68d330eca7baca5cee9c4a74cdc4b7732a43933021f3db7e0297fb68ce25a>

The anchor establishes a timestamped digest. It does not prove a supplier payment, invoice authenticity or production approval.

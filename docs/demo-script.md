# Three-minute demo script

| Time | Action | Line to say |
|---|---|---|
| 0:00–0:20 | Paste the synthetic invoice screenshot and open the draft | “AI can read the request, but it cannot authorize itself.” |
| 0:20–0:45 | Run the fee-overrun incident | “The proposal fits before fees and exceeds the real budget after fees.” |
| 0:45–1:15 | Run the unsafe candidate | “The changed rule re-allows the same old incident, so the release gate turns red.” |
| 1:15–1:40 | Apply the correct rule and replay | “Same evidence, no new model call, no payment. The regression returns green.” |
| 1:40–2:05 | Open two representative boundary cases | Show one micro-USDC below budget and same merchant name with another address. |
| 2:05–2:30 | Open the read-only receipt and Base Sepolia proof | “This is a zero-value digest anchor, not a supplier payment.” |
| 2:30–3:00 | Show the SDK command and GitHub Actions | “Every payment-policy change can replay the incident set before merge.” |

Keep the browser on fixture mode until the optional integration evidence segment. Never expose `.env`, the Kiln dashboard key or a testnet private key in the recording.
